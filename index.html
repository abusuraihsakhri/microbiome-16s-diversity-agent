16S Diversity Explorer

Descriptive alpha and beta diversity from ASV / OTU read counts.

View repository ↗

1. Input count table

Rows are samples; columns are ASVs / OTUs. Enter nonnegative integer read counts. No files are uploaded to a server.

The first column must be sample_id. Each sample must contain at least one read.

Data handling: computation and CSV exports take place entirely in this tab. No tracking scripts, remote fonts, accounts, or API keys.

Bray–Curtis dissimilarity

Computed from relative abundances; zero = identical composition, one = no shared ASVs / OTUs.

Interpretation and limitations. Shannon uses natural logarithms; Simpson is 1 − Σp²; Chao1 uses the bias-corrected singleton/doubleton estimator; Pielou J = H / ln(observed richness). Bray–Curtis is computed from per-sample relative abundances rather than raw library sizes. These are descriptive, sampling-depth-sensitive quantities; no rarefaction, compositional normalization beyond relative abundance, hypothesis testing, batch correction, or ecological inference is performed. UniFrac and PERMANOVA are not computed: UniFrac requires a phylogenetic tree, and PERMANOVA requires group metadata and permutation testing. Do not interpret these outputs as diagnoses or clinical decisions.
